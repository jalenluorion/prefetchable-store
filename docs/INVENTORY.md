# What was tried: inventory

Everything built, measured, dropped or left for later in the work behind this release (session measurements of
2026-11-21 and 2026-11-22). Five lists: what is in the release (each item maps to a mode, profile or default in
[MANIFEST-PRESETS.md](MANIFEST-PRESETS.md)), what was dropped, what was not pursued, what is still to do, and what is
built and kept but not a default.

**Conditions.** Machine: base M4 MacBook Pro 16 GB unless "phone" (iPhone 15 Plus, A16, 4.12-4.27 GB available to the
app). "35B" = Qwen3.6-35B-A3B, "Inkling" = Inkling 2 Mini. Prompts: "prose" = the Pittsburgh prompt (9-10 tokens),
"code" = the coding chat prompt (357 / 462 tokens), "file rewrite" / "new file" = OpenCode tool-call turns. Timings
are tokens/s of decode, 400 tokens greedy, two runs shown as "a / b", unless stated. "Others" = mean CPU of other
processes (100% = one core). Read counts (MB per token, hit rate) do not depend on machine load; tokens/s does.

**Evidence.** Paths under `results/` are in this repository. `engine/`, `jobs/`, `local/`, `ctl/` and `HL/` name
research notes and run folders that are not.

**How solid** (dropped list): SOLID = a clean measurement, repeated or load-independent (read counts, validated cache
replays, held-out cluster metrics). **Weak evidence** = one run, a busy machine, one model only, a sizing model or
simulation used for a speed claim, or measured before the prefill-cache fix: the item was dropped, but the case
against it is not closed. A re-check on a quiet machine is in progress for thread counts, reader counts and split
reads, read priority on the 35B, the exact greedy head, Inkling's 4-bit routers and a lower names threshold, names
inside verify passes at a large cache, and router names on or off during agent turns.
